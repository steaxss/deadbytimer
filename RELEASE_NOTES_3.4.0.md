# Dead by Timer 3.4.0 — Required transition

This is the final update for the previous timer. Install it through the update
prompt in your current application.

After restarting, the timer is disabled and the application offers the new
**Dead by Timer 4.0.0**. Choose **Download Dead by Timer**, then
**Install Dead by Timer** and complete the Windows Setup.

Administrator approval is required. Previous timer settings are not transferred.
The previous application remains installed but cannot be used as a timer.

New users should download directly from
[deadbytimer-v2](https://github.com/steaxss/deadbytimer-v2/releases/latest).

This repository is retained to deliver the final transition update to existing
installations. Future versions are distributed through deadbytimer-v2.
