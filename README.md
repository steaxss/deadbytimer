# Dead by Timer

This version of Dead by Timer is no longer maintained or available for use as a timer. It has been replaced by [Dead by Timer v2](https://github.com/steaxss/deadbytimer-v2).

The [final release (v3.4.0)](https://github.com/steaxss/deadbytimer/releases/tag/v3.4.0) remains available to help existing installations migrate to the new app.
